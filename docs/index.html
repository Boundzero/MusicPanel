MusicPanel

A touchscreen controller for Music Assistant. Flash it right here in your browser.

Your browser can't flash devices. Please use Chrome, Edge, Brave, or Opera on desktop (not Firefox or Safari). You need to allow serial access to continue.
Plug the panel in via USB, then click Install.
Supported browsers: Chrome, Edge, Brave, Opera — on Windows, macOS, Linux, or ChromeOS. Firefox and Safari don't support in-browser flashing.
Windows: if no serial port appears, install the CH340 USB driver. macOS and most Linux distros already include it.

After flashing — set it up from your phone

  1. The panel creates a Wi-Fi network named MusicPanel-XXXX. Join it on your phone.
  2. A setup page opens (or visit http://192.168.4.1).
  3. Enter your Wi-Fi, your Music Assistant server address + token, and your time zone and location.
  4. Save — the panel reboots and connects. Pick your room in Settings and you're playing.

Getting a Music Assistant token

In Music Assistant: Settings → your profile → create a Long-Lived Token, then paste it into the setup page.

Hardware

This firmware is for the Guition/JCZN ESP32-4848S040 (4" 480×480 IPS, ESP32-S3). It won't run on other boards. See the GitHub repository for details and source.
